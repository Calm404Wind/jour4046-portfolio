# ZENG Yi CV

This CV website presents the complete English CV first, followed by the complete Traditional Chinese CV. Both versions include an education and work experience timeline.

## Website entry

Open `index.html`. The site is a standalone HTML document and can be published with GitHub Pages. The empty `.nojekyll` file keeps the site as static files.

## Updating the website

Edit the maintained CV HTML source, export a new standalone HTML document, and replace `index.html` with that export. Keep the English version before the Chinese version, then check both desktop and mobile layouts before publishing the updated files.
